# Buy or Wait — solution

## Run

From the repository root:

```bash
python code/main.py
```

## Requirements

Python 3.10+ (tested with 3.14). Standard library only. No API keys or `.env` for v1.

## Output

Full runs write `output.csv` at the repository root (one row per `dataset/requests.csv` request). Phase 0 is a scaffold only and does not write predictions yet.
